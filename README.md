# TraceVA

Explainable agentic visual analytics through interactive analytical provenance.

- `backend/`: FastAPI + SQLite backend ([setup](backend/README.md))
- `frontend/`: React prototype: chat, charts, claim provenance, graph ([setup](frontend/README.md))
- `scripts/start-demo.ps1`: demo mode (recorded model responses replayed, all computation live)
- `docs/reports/interim-metrics.md`: interim progress metrics
- `datasets/`: local raw datasets, not committed ([instructions](datasets/README.md))
- `docs/architecture.md`: current architecture (as built)
- `docs/decisions/`: architecture decision records
- `docs/TRACEVA_BACKEND_CONTEXT.md`: design brief
